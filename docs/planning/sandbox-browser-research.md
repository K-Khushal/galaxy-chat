## Execution, security and accounting boundaries

Cloudflare's current Sandbox docs describe 1.0; 0.x references are legacy. Containers default to Internet disabled; outbound interception can mediate destinations. Every process inside one sandbox shares trust, including root capabilities: use a fresh sandbox per owned job and keep provider secrets outside it. [Security](https://developers.cloudflare.com/sandbox/concepts/security/).

Cloudflare inactivity is not a wall deadline: activity/streams keep instances running; configured inactivity can reach six hours. `destroy()` stops immediately, ephemeral files disappear, and deployment is not cancellation. Persist bounded outputs first. [Lifetime](https://developers.cloudflare.com/sandbox/concepts/lifetime/). Modal provides `block_network`; partial allowlists still permit unrestricted DNS. Use full blocking initially. [Networking](https://modal.com/docs/guide/sandbox-networking).

Browser Run defaults to 60-second inactivity, extendable to 20 minutes, with no fixed active-session lifetime. Explicitly close and verify terminal status; `closeSession` can return `closing`. Host-specific outbound routing alone is not proof that every other destination is denied. [Limits](https://developers.cloudflare.com/browser-run/limits/), [session API](https://developers.cloudflare.com/browser-run/reference/browser-binding-api/), [routing](https://developers.cloudflare.com/browser-run/features/outbound-workers/). Browserbase downloads enter provider storage; disable arbitrary downloads initially. [Downloads](https://docs.browserbase.com/platform/browser/files/downloads).

Browser Run's `X-Browser-Ms-Used` measures duration, not final dollars. Modal Starter lacks the Team/Enterprise billing-report API. No reviewed response establishes an authenticated, complete per-job cost receipt covering startup, orphan lifetime, storage, egress, rounding and fees. Unknown termination/cost must retain liability, never imply refund. [Browser billing](https://developers.cloudflare.com/browser-run/pricing/), [Modal reports](https://modal.com/docs/guide/billing#generating-billing-reports).

## Local implementation and activation gates

At this baseline, jobs allow **five attempts**, not five steps: ten-minute shared wall, one active/owner, two globally, twenty-second leases; ToolStore has three steps/four calls. These are tighter than provider concurrency and long session lifetimes. Artifact content is 128 KiB, tool results 4 KiB, attachments 2 MiB; retain those tighter output bounds. Provider-wide output maxima are not established here. [Jobs](../operations/jobs.md), [contracts](../../lib/jobs/contract.ts), [tools](../../lib/tools/contract.ts), [artifacts](../../lib/artifacts/contract.ts), [attachments](../../lib/attachments/contract.ts).

Proposed seam: immutable owned source/image/runtime/network-policy digest; bounded input/output; fenced admission; persisted provider handle; start/status/terminate/reconcile; explicit uncertain outcome. Production factory returns typed unavailable with no activation flag. Test fixtures simulate expiry, duplicates, cancellation races, oversize output and unknown cost; never execute supplied code or browse remotely. Existing fixture retries cannot safely replay an external entry.

Preserve `Acredit + Amcp + Kinfra + Kfees + Ksafety + Lcarried ≤ B ≤ $10`. Count the entire $5 baseline once, leaving at most $5 for everything else; B below $5 excludes Paid. Supabase Free includes 500 MB DB/1 GB files/5 GB egress and may pause; Pro starts $25. [Budget](../operations/platform-budget.md), [Supabase](https://supabase.com/pricing).

Before activation require verified account plans/quotas, taxes/payment fees, shared consumption, bounded orphan exposure, destination isolation, terminal/cost evidence and an updated complete capacity snapshot.
